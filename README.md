# Google AI検索 - 右クリックで「とは」検索

選択したテキストに「とは」を付けてGoogle検索を新しいタブで開くChrome拡張機能です。

## 機能

- Webページ上のテキストを選択して右クリック
- コンテキストメニューに「"選択テキスト"とは で Google AI 検索」が表示される
- クリックすると新しいタブで「選択テキスト + とは」のGoogle検索結果が開く

## インストール方法

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. ダウンロードしたフォルダを選択する

## 使い方

1. 任意のWebページでテキストを選択する
2. 右クリックしてコンテキストメニューを開く
3. 「"選択テキスト"とは で Google AI 検索」をクリック
4. 新しいタブでGoogle検索結果が表示される

## セキュリティ

- **Manifest V3**: 最新のChrome拡張仕様を使用
- **最小限の権限**: `contextMenus` のみ使用（ユーザーデータへのアクセスなし）
- **入力制限**: 検索クエリは200文字に制限
- **安全なURL構築**: `URL` APIを使用してクエリパラメータを安全にエンコード
- **外部API不使用**: 無料のGoogle検索のみ使用
- **CSP設定**: Content Security Policyで外部スクリプトの実行を防止
